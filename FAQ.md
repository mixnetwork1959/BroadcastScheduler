# Frequently Asked Questions

## Does Broadcast Scheduler modify RadioBOSS?

No.

The application is completely read-only.

## Where is Admin.sdl located?

Typical location:

    C:\Users\<USERNAME>\AppData\Roaming\djsoft.net\RadioBOSS_xxxxxxxxx\Presets\Schedule\

## Why are some events highlighted?

Multiple scheduler events are configured to start at exactly the same
scheduled time.

## Does the program support all RadioBOSS scheduler options?

Currently it supports the most commonly used scheduling features.

Support for additional options will be added in future releases.

## Can I edit events?

No.

Broadcast Scheduler is an analysis tool only.
