Broadcast Scheduler 4.2.0 – Public Calendar

Included files:
- gui.py
- gui_public_calendar.py
- website_generator.py

Installation:
1. Copy all three files into the BroadcastScheduler project folder.
2. Replace the existing files.
3. Start: py scheduler.py

Usage:
1. Select only public music programs.
2. Set public names, descriptions and colors.
3. Click Publish Website.

Output:
website_output/index.html

New in 4.2.0:
- Week view only
- Lower day list removed
- Publish Website button
- Current-time red line on today's column
- Current program highlighted with orange glow
- Live progress bar inside current program
- LIVE NOW panel above calendar
- Europe/Sofia station time
- Technical nearly-all-day blocks excluded
